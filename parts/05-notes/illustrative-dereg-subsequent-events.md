# Note — Events after the end of the reporting period (dereg) / 報告期結束後事項（撤銷登記）

**Allen lock 2026-09-19.** Variant **B** (Excel long form) · EN + editorial 繁體中文.

**Rules**
- **EN source:** white-label Excel `Y1-NL.xlsx` / `Y1-NA.xlsx` subsequent-events block (sheet 13 / 12).
- Use for **cessation / planned deregistration** packs.
- Heading: **Events after the end of the reporting period** (Excel) — also acceptable as “Subsequent events” in live packs if already used; prefer Excel heading for new locks.
- **Settle / waive** of outstanding balances stays on **s.750(2) undertaking** (SoFP note / directors’ balances / Note 11 Variant C) — **not** inside this subsequent-events note.
- Short 天書/TK #54 variant (liabilities settled/waived inside subsequent-events) is **not** the locked default after this lock.
- Break-up basis remains in **Note 2** only; AR has **no** dereg EOM.

---

## English (Variant B — locked)

```
EVENTS AFTER THE END OF THE REPORTING PERIOD

Subsequent to the end of the reporting period, the Company intends to
apply for deregistration with the Companies Registry under Section 750
of the Companies Ordinance (Cap. 622).

There are no other material events subsequent to the end of the reporting
period that require disclosure in these financial statements.
```

## 中文（編輯譯文 — locked with B）

報告期結束後事項

於報告期結束後，本公司擬根據《公司條例》（第622章）第750條向公司
