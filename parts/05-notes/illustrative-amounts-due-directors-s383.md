# Note 11 — Amounts Due from/(to) the Directors (Cap.622 s.383(1)(d))

**Allen lock 2026-09-14** (base + Variants A and C). Working bible specimen.

**Rules**
- Separate statutory note under **section 383(1)(d)** of the Companies Ordinance.
- Heading always **plural**: Amounts Due from/(to) the Directors / 應收／（應付）董事款項 — even if only one director.
- Attribute balances to person(s) who were **director(s) as at the year-end date**; name each director.
- Aggregate total must **tie** to the directors line in Note 13 (from) / Note 15 (to).
- SoFP face does **not** show a separate directors line — only Accounts and other receivables / payables.
- Directors appointed **before** year end are simply named in the table — **no** extra change-of-directorship paragraph (Variant B not used).

Base specimen: legacy P-20260715-01 (APPROVED 2026-07-15), upgraded for always-plural heading + two-layer tie to Notes 13/15.

```

Section 383(1)(d) of the Companies Ordinance are as follows:-

| Name of directors | [CY] | [PY] |
|:---|---:|---:|
| [DIRECTOR NAME] | [XX,XXX] / ([XX,XXX]) | [XX,XXX] / ([XX,XXX]) |
| | --------- | --------- |
| | [XX,XXX] / ([XX,XXX]) | [XX,XXX] / ([XX,XXX]) |
| | ========= | ========= |

The amounts due from/(to) directors are unsecured, interest-free and
have no fixed repayment terms.
```

Brackets = due to directors.

## Variant A — Post-YE succession (Allen lock 2026-09-14)

**When:** All directors as at year end resigned, and new directors were appointed **after** the reporting date. Table still names the **YE-end** directors.

Append after the base unsecured/interest-free sentence:

### English

```
Subsequent to the reporting date, all the directors as at [YE DATE]
resigned and new directors were appointed. The succeeding directors
have agreed to assume responsibility for the outstanding balances and
undertake not to demand repayment of the amounts due to the directors
until the Company is financially capable to do so.
```

Use “due from” / “due to” to match the balance direction. If the balance is **due from** directors, omit or adapt the “not demand repayment” sentence as it applies to amounts **due to** directors.

### 中文

```
於報告日期後，於[年結日]在任之全體董事已辭任，並已委任新董事。
繼任董事已同意承擔未償還結餘之責任，並承諾在本公司具備財務能力
償還前，不會要求償還應付董事款項。
```

## Variant C — Deregistration / cessation (Allen lock 2026-09-14)

**When:** Company ceased business / planned deregistration (break-up basis). Table still names YE-end directors.

Append after the base unsecured/interest-free sentence (may be combined with Variant A if both apply):

### English

```
Given the Company's cessation of business and planned deregistration,
the directors have confirmed that the amounts due from/(to) directors
will be settled or formally waived prior to the submission of the
deregistration application to the Companies Registry, as required under
Section 750(2) of the Hong Kong Companies Ordinance.
```

Align from/to with the balance. Cross-refer the s.750(2) undertaking in Note 2 / SoFP note where used.

Optional (aligns with Case 4 DR):

```
There will be no future appointments of directors.
```

### 中文

```
基於本公司已停止業務並擬申請撤銷登記，董事已確認應收／（應付）
董事款項將於根據《香港公司條例》第750(2)條向公司註冊處提交撤銷
登記申請前悉數結清或正式豁免。
```

Optional:

```
將不會再委任董事。
```
