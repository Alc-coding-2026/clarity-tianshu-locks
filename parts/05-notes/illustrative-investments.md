# Equity holdings disclosure notes / 股權持有披露附註

**Allen lock 2026-10-02.** EN + editorial 繁體中文. Chinese is **not** an official HKICPA translation.  
House disclosure notes for INV-S / INV-A / INV-J / INV-E. Note numbers remain **`[N]`** placeholders.

**Scope / 適用：** Eligible SME-FRS Hong Kong private company limited by shares; company-level; normal annual period; cost model.  
符合 SME-FRS 資格之香港私人股份有限公司；公司層面；正常年度；成本模式。

**SoFP face captions (locked 2026-09-19):** Investments in subsidiaries / associates / joint ventures / **Equity investments**.  
**財務狀況表面列標題（2026-09-19 鎖定）：** 於附屬公司／聯營公司／合營企業之投資／**股權投資**。

**Not this page / 不屬本頁：**
- Amounts **due from/to** subsidiaries, associates or joint ventures stay in locked **Notes 13/15** — do **not** put dues on these investment notes.  
  應收／應付附屬、聯營、合營款項留在已鎖定 **Notes 13/15** — **勿**放入本頁投資附註。
- Accounting-policy wording for PPE / sub / asso / JV / equity investments: locked Note 2 modules in [illustrative-ppe-investment-policies.md](./illustrative-ppe-investment-policies.md).  
  會計政策文句見已鎖定附註2模組。
- Income tax Note 5 format is locked separately — **untouched** by this draft.  
  所得稅 Note 5 格式已另行鎖定 — 本草稿**不改動**。

## Rules / 選用規則

- Select **each module independently**; **omit unused modules** in a live pack.  
  **逐模組**選用；實務套裝**刪除不適用模組**。
- Note numbers remain **`[N]`** placeholders (wiki ancestry N-07 / N-08 / N-09) until a later house-sequence lock.  
  附註編號維持 **`[N]`** 佔位（wiki 先祖 N-07／N-08／N-09），待其後編定套裝次序。
- Place of incorporation = **jurisdiction only** (e.g. Hong Kong, British Virgin Islands) — **never a city**.  
  註冊成立地點＝**司法管轄區** — **不得寫城市**。
- Sub / asso / JV: **no equity accounting**; stated at **cost less accumulated impairment**.  
  附屬／聯營／合營：**不**用權益法；按**成本減累計減值**列賬。
- **Joint ventures** = **separate note** — do **not** merely rename the associates note.  
  **合營企業**＝**獨立附註** — **勿**只把聯營附註改名。
- Non-consolidation full basis: insert the matching locked **A / B / C / S** block from [illustrative-non-consol-bases.md](./illustrative-non-consol-bases.md) **after** the subsidiaries schedule. **Do not** paste Variant S as the only text. Note 2(c) = cross-reference only ([non-consolidation-placement.md](./non-consolidation-placement.md)).  
  不合併完整基準：於附屬公司附表**之後**插入已鎖定 **A／B／C／S** 對應區塊。**勿**只貼 Variant S。附註2(c) 只作交叉引用。

## Situation map / 情況對照

| Code | Module | 模組 | Use when |
| --- | --- | --- | --- |
| **INV-S** | Investment in subsidiaries | 於附屬公司之投資 | Company holds one or more subsidiaries |
| **INV-A** | Investment in associates | 於聯營公司之投資 | Significant influence (typically 20–50%); not sub or JV |
| **INV-J** | Investment in joint ventures | 於合營企業之投資 | Joint control; separate note if present |
| **INV-E** | Equity investments | 股權投資 | Other equity holdings (not sub / asso / JV) |

Delete INV-A / INV-J / INV-E (and INV-S) when the company has none of that class.

House SoFP caption: **Equity investments** (other equity holdings that are **not** subsidiaries, associates or joint ventures). Align measurement and MV disclosure with locked Note 2 in [illustrative-ppe-investment-policies.md](./illustrative-ppe-investment-policies.md).  
財務狀況表面列標題：**股權投資**（附屬、聯營、合營**以外**之其他股權持有）。計量及市值披露與已鎖定附註2對齊。

**House caption (locked):** note heading is **Equity investments** / **股權投資** only — do **not** use the legacy wiki N-09 alias “Financial assets at cost” / 「按成本計量之金融資產」.  
**行內標題（已鎖定）：** 附註標題只用 **Equity investments**／**股權投資** — **勿**使用舊稱 wiki N-09「按成本計量之金融資產」。
