# Directors' Remuneration / 董事酬金

**Allen lock 2026-09-19.** Common SME-FRS note · EN + 繁體中文.

**Rules**
- Always plural: **directors' remuneration** / **董事酬金** (even if one director).
- **Version A — sentence only** when none paid or payable.
- **Version B — table** when amounts are disclosed: Directors' fees, Salaries and other emoluments, Retirement benefit scheme contributions, total.
- Drop nil rows in Version B only if firm practice for that pack allows; specimen keeps all three lines when using the table.

---

## Version A — Sentence only (none)

### English

```
[N]. DIRECTORS' REMUNERATION

No directors' remuneration was paid or payable in respect of the
[year / period] ([PY]: nil).
```

### 中文

```
[N]. 董事酬金

本[年度／期間]並無已付或應付董事酬金（上年度：無）。
```
