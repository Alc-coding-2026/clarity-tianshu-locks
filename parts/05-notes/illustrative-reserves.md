## Rules / 選用規則

- Wiki ancestry: **N-17 Reserves** movement table.  
  Wiki 先祖：**N-17 儲備**變動表。
- **If SOCIE is presented** (separate statement **or** the locked “Changes in equity” note): **omit this reserves note** — SOCIE already carries the movement.  
  **若已呈列 SOCIE**（獨立報表**或**已鎖定「權益變動」附註）：**省略本儲備附註** — SOCIE 已載變動。
- Use this note only when the pack presents equity movement **here** instead of a full SOCIE (or when a reserves-only supplement for other reserve columns is later required).  
  僅於套裝以**本附註**代替完整 SOCIE 呈列權益變動時使用（或其後需要其他儲備欄之補充時）。
- Closing balance must **tie** SoFP **Retained earnings**.  
  期末結餘須與財務狀況表「保留盈利」**核對**。
- Opening / closing labels use **prior YE date** and **current YE date** — not “1 January …”. Align with locked SOCIE date style.  
  期初／期末標籤用**上年結日**及**本年結日** — 不用「1月1日…」。與已鎖定 SOCIE 日期風格一致。
- Note number remains **`[N]`** (wiki **N-17**) until a later house-sequence lock.  
  附註編號維持 **`[N]`**（wiki **N-17**），待其後編定套裝次序。
- Default column: **Retained earnings** / **保留盈利**. Add other reserve columns only when live (share premium, etc.).  
  預設欄：**保留盈利**。僅於實際存在時加其他儲備欄（例如股份溢價）。
- Use **Accumulated losses** / **累計虧損** labels when the balance is negative.  
  結餘為負時改用**累計虧損**標籤。

## RS-A — Retained earnings movement (wiki N-17 shape) / 保留盈利變動（wiki N-17 形）

### English

```
[N]. RESERVES

| | Retained earnings | Total |
|:---|---:|---:|
| At [PY YE DATE] | [XX,XXX] | [XX,XXX] |
| Profit/(loss) for the year | [XX,XXX] | [XX,XXX] |
| Dividends paid | ([XX,XXX]) | ([XX,XXX]) |
| | --------- | --------- |
| At [CY YE DATE] | [XX,XXX] | [XX,XXX] |
| | ========= | ========= |
```

### 中文

```
[N]. 儲備

| | 保留盈利 | 總額 |
|:---|---:|---:|
| 於[上年結日] | [XX,XXX] | [XX,XXX] |
| 本年度溢利／（虧損） | [XX,XXX] | [XX,XXX] |
| 已付股息 | ([XX,XXX]) | ([XX,XXX]) |
| | --------- | --------- |
| 於[本年結日] | [XX,XXX] | [XX,XXX] |
| | ========= | ========= |
```

**Notes / 備註**
- Omit **Dividends paid** when nil. Other live movements (allotment affecting reserves, capital reduction touching RE): follow locked SOCIE optional-row vocabulary — do not invent alternate labels.  
  **已付股息**為零則刪。其他實際變動（影響儲備之配發、涉及保留盈利之減少股本）：沿用已鎖定 SOCIE 可選行用詞 — 勿另創標籤。
- Prefer presenting the full locked **SOCIE** rather than this reserves-only note when share capital also moved.  
  若股本亦有變動，優先呈列完整已鎖定 **SOCIE**，而非僅本儲備附註。
