# Note 1 — Presentation / functional currency (non-HKD and changes) / 呈列及功能貨幣

**Status: LOCKED — Allen 2026-10-17 (t310u).** EN + editorial 繁體中文 (not an official HKICPA translation).

**Rules**
- HKD default stays Note 1 Block A ("presented in Hong Kong dollars ("HK$"), which is the functional currency of the Company").
- Use Path A / B / C only when the facts support it. Never invent a reason or exchange rate.
- Note 2 FX translation policy (locked 2026-09-19) is unchanged.
- Path C pairs with Path A (presentation = new functional) or Path B (still different).

## Path A — presentation = functional, not HKD (达利得 face)

```text
The financial statements are presented in [CURRENCY NAME] ([ABBR]), which is also the functional currency of the Company.
```
```text
本財務報表以本公司之功能貨幣[貨幣名稱]（「[縮寫]」）呈列。
```

## Path B — presentation ≠ functional (SME-FRS §15.15)

```text
The financial statements are presented in [PRESENTATION CURRENCY] ([ABBR]). The functional currency of the Company is [FUNCTIONAL CURRENCY]. The directors consider [PRESENTATION CURRENCY] to be more appropriate for [REASON].
```
```text
本財務報表以[呈列貨幣]（「[縮寫]」）呈列。本公司之功能貨幣為[功能貨幣]。董事認為以[呈列貨幣]呈列更為合適，原因為[理由]。
```

## Path C — change of functional currency

```text
During the year, the Company changed its functional currency from [OLD] to [NEW] because [REASON]. Transactions and balances have been translated into [NEW] from the date of the change. Comparative amounts are presented in [PRESENTATION CURRENCY USED FOR COMPARATIVES]. The financial statements are presented in [PRESENTATION CURRENCY], which [is also / is not] the functional currency of the Company.
```
```text
於本年度，本公司因[理由]將功能貨幣由[舊貨幣]改為[新貨幣]。自更改日期起，交易及結餘已換算為[新貨幣]。比較數字以[比較呈列貨幣]呈列。本財務報表以[呈列貨幣]呈列，該貨幣[亦為／並非]本公司之功能貨幣。
```

**Locked [REASON] options (use only if factual):**
1. the Company's primary economic environment changed to one in which [NEW] is the currency that mainly influences sales prices and costs
2. the Company now settles a substantial majority of its sales and purchases in [NEW]

Do not use "management convenience" or other unlisted reasons without Allen.

## Tax schedule caption (FS not in HKD)

```text
(Converted from [PRESENTATION CURRENCY] to Hong Kong Dollars)
```
```text
（由[呈列貨幣]換算為港元）
```
Exchange rate is case-specific — **no** 1:1 house default.
