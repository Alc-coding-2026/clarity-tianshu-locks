# Bank loans / borrowings / 銀行貸款／借貸

**Allen lock 2026-10-02.** EN + editorial 繁體中文. Chinese is **not** an official HKICPA translation.  
Bank loans disclosure. Omit when none on SoFP. Note numbers remain **`[N]`** placeholders.

**Scope / 適用：** Eligible SME-FRS Hong Kong private company limited by shares; company-level; normal annual period.  
符合 SME-FRS 資格之香港私人股份有限公司；公司層面；正常年度。

**SoFP face caption (locked 2026-09-19):** **Bank loans** — shown separately as **current** and **non-current** (same caption, different section).  
**財務狀況表面列標題（2026-09-19 鎖定）：** **銀行貸款** — 按**流動**及**非流動**分別列示（同一標題，不同部分）。

**Not this page / 不屬本頁：**
- Amounts **due to** directors / shareholders / related companies stay in locked **Notes 13/15** (+ s.383 Note 11 where applicable) — **not** bank loans.  
  應付董事／股東／關聯公司款項留在已鎖定 **Notes 13/15**（及適用時 s.383 Note 11）— **不是**銀行貸款。
- Finance-lease liabilities / other borrowings captions: only if live and a separate face line is later locked — do not invent here.  
  融資租賃負債／其他借貸面列：僅於實際存在且其後鎖定獨立面列時處理 — 本頁不另行發明。

## Rules / 選用規則

- **Omit the entire note** when there are **no** bank loans on the SoFP (current and non-current, both dates).  
  財務狀況表（流動及非流動、兩個日期）**並無**銀行貸款時**省略整則附註**。
- Current / non-current **face split is already on the SoFP** — this note reconciles those face amounts and adds terms / security placeholders.  
  流動／非流動**面列拆分已在財務狀況表** — 本附註核對該等面列金額並加入條款／抵押佔位。
- Note number remains **`[N]`** until a later house-sequence lock.  
  附註編號維持 **`[N]`**，待其後編定套裝次序。
- Classify from facility letters, repayment schedules and security documents — never from caption habit alone.  
  分類須依融資函、還款表及抵押文件 — 不得只憑標題習慣。

**Notes / 備註**
- Current + non-current rows must **tie** the respective SoFP **Bank loans** face lines.  
  流動＋非流動列須分別**核對**財務狀況表「銀行貸款」面列。
- Delete nil maturity bands; never leave bracketed examples in issued FS.  
  刪除為零之到期區間；已發出財務報表不得留下方括號示例。
- Overdrafts classified as bank loans on the face: include in the current portion and describe in the terms sentence.  
  於面列歸入銀行貸款之透支：計入流動部分，並於條款句說明。
- Guarantees given **by** the Company for others belong under contingencies — not this loan note.  
  本公司**為他人**提供之擔保屬或然事項 — 不放入本貸款附註。
