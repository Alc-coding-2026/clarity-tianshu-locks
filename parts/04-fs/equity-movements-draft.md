# Statement of changes in equity / 權益變動表 (SOCIE)

**Allen lock 2026-09-19.** EN + 繁體中文.

**Rules**
- Present as a **separate statement** *or* as a **note** (SME-FRS §1.32). Comparatives for this reconciliation are **not** required.
- Opening / closing labels use **prior YE date** and **current YE date** — not “1 January …”.
- **No** “Total income and expense for the year” subtotal row.
- Default rows: opening balance · Profit/(Loss) for the year · closing balance.
- Optional live-only rows: **Dividends paid** · **Allotment of ordinary shares** (further / new issue) · **Capital reduction** (`減少股本` — Cap.622 wording; not 股本削減).
- Omit nil optional rows in a real pack. Closing equity must **tie** SoFP.
- One share-capital class + retained earnings assumed; add columns only when other reserves / classes are live.
- Use loss / accumulated-loss labels where applicable.
