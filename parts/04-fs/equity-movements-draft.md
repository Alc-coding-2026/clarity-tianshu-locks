# Statement of changes in equity / 權益變動表 (SOCIE)

**Version 1 — Allen lock 2026-09-19 (rows and labels); two-year house form Allen 2026-10-19.** EN + 繁體中文.

**Version 2 — change in functional currency (exchange reserve): LOCKED, Allen 2026-10-19.**

**Rules**
- Present as a **separate statement** *or* as a **note** (SME-FRS §1.32). House form shows **TWO years** (comparative + current), Allen 2026-10-19. SME-FRS §1.32 does not itself require comparatives for this reconciliation.
- Opening / closing labels use **year-end dates** — prior-prior YE, prior YE, and current YE — not “1 January …”.
- **No** “Total income and expense for the year” subtotal row.
- Default rows, each year: opening balance · Profit/(Loss) for the year · closing balance. The comparative closing balance is the current opening balance (one row, not repeated).
- Optional live-only rows (either year): **Dividends paid** · **Allotment of ordinary shares** (further / new issue) · **Capital reduction** (`減少股本` — Cap.622 wording; not 股本削減).
- Omit nil optional rows in a real pack. Closing equity must **tie** SoFP.
- One share-capital class + retained earnings assumed; add columns only when other reserves / classes are live. Exchange reserve is Version 2 only.
- Use loss / accumulated-loss labels where applicable.

## Version 2 — change in functional currency (exchange reserve)

**LOCKED, Allen 2026-10-19.** Allen 2026-10-19 asked for one more version and locked it (“Lock both”). Use this version only for a change in functional currency; Version 1 remains the house default.

Cross-ref: [parts/05-notes/illustrative-currency-note1.md](../05-notes/illustrative-currency-note1.md) Paths A / B / C (locked 2026-10-17). Path C is the change of functional currency; it pairs with Path A (presentation = new functional) or Path B (presentation still different).

**Rules**
- Columns: Share capital | Exchange reserve | Retained earnings | Total. ZH column head for the reserve: **匯兑儲備** (locked).
- Two years. Same row structure as Version 1, plus one row in the **year of change** only: **Exchange differences arising on change in functional currency** / 「功能貨幣變更產生之匯兑差額」.
- That row carries the amount in the **Exchange reserve** column only. **Share capital** and **Retained earnings** are **—**. Total equals the exchange-reserve amount.
- Share capital stays at its **historical amount**. It is not retranslated. There is **no movement row** that changes share capital for the currency change. Allen 2026-10-19: “i dun prefer change in share capital”. The **entire** translation difference is taken to exchange reserve.
- A real capital transaction in that year (issuance, allotment, capital reduction) still uses the Version 1 row and does move share capital. The currency change itself does not.
- Place the exchange-difference row in the year the functional currency changed (comparative or current), after Profit/(Loss) and before owner-transaction rows. The illustration puts the change in the year ended 31 December 2025, so the comparative exchange reserve is nil (**—**). If the change was in the comparative year, put the row there and carry the reserve into the current opening balance. Do not repeat the row in a year with no change.
- Omit nil optional rows. Closing equity, including exchange reserve, must **tie** SoFP. Use loss / accumulated-loss labels where applicable. Year-end dates, not 1 January. No “Total income and expense for the year” row.
- The translation difference is case-specific. This version does **not** set a 1:1 rate.
